# Семейство ЧМЭ3 — Stage 2 Interactive checkpoint

Статус: **COMPLETE**  
Дата: 2026-10-01

## Область

Интерактивный слой подготовлен для трёх профилей семейства:

- `chme3-base` — ЧМЭ3;
- `chme3t-rheostatic` — ЧМЭ3Т;
- `chme3e-electronic` — ЧМЭ3Э.

Это расширяет критерий Stage 2 до: **Атлас + функциональные электрические/пневматические схемы + runtime-ready интерактивные схемы**.

## Модель интерактива

Используется семейный контракт `common/interactive_scheme_contract.json`, совместимый с существующей моделью `TechnicalHotspot` и hotspot/flow подходом интерактивного Атласа приложения.

Основной режим — `SEMANTIC_CANVAS`:

- полотно строится из проверенных узлов и направленных связей;
- каждый hotspot связан со стабильным `equipmentId`;
- нажатие ведёт к карточке оборудования;
- поиск по обозначению/алиасу приводит к нужному `equipmentId` и подсветке hotspot;
- переход из диагностики выполняется по `equipmentId` с фокусом на соответствующей схеме;
- обратный индекс позволяет из карточки оборудования получить все схемы, где этот узел присутствует;
- профильные gate исключают оборудование чужого исполнения.

`SOURCE_OVERLAY` оставлен отдельным опциональным режимом. Координаты поверх исходного заводского/учебного листа считаются готовыми только после идентификации конкретного изображения и проверки координат именно на нём. Семантические координаты текущего canvas не выдаются за координаты на заводской принципиальной схеме.

## Покрытие

Общие для семейства интерактивные представления:

1. топливная система;
2. масляная система;
3. водяная система/охлаждение;
4. наддув и газообмен;
5. привод вспомогательных механизмов;
6. пневматическая и тормозная система;
7. экипажная часть;
8. механическая часть тормоза;
9. дизель — топливо, регулирование и защита.

ЧМЭ3 дополнительно имеет отдельные интерактивные виды тяговой электрической передачи и цепей запуска/управления.

ЧМЭ3Т наследует только допустимый общий тягово-управляющий слой и получает собственный `CHME3T-INT-EDB` для реостатного тормоза. ЭДТ физически профиль-гейтирован и не доступен ЧМЭ3/ЧМЭ3Э.

ЧМЭ3Э имеет шесть собственных интерактивных видов:

- электронное регулирование тяги и мощности;
- автоматическое ослабление возбуждения;
- электронная логика пуска;
- обогрев водяной системы от тягового генератора;
- внешний прогрев неработающего дизеля;
- управление в одно лицо.

## QA

`qa/validate_chme3_interactive.py` проверяет:

- существование всех `equipmentId`;
- границы и минимальный размер hotspots на полотне 1600×900;
- отсутствие дублирующихся hotspots внутри представления;
- разрешимость `sourceSchemeRef`;
- наличие кликабельного hotspot для каждого конца каждой направленной связи;
- электрическое и пневматическое интерактивное покрытие каждого профиля;
- отсутствие CHME3T-узлов у ЧМЭ3Э и CHME3E-узлов у ЧМЭ3Т;
- обязательное наличие EDB view у ЧМЭ3Т;
- отсутствие EDB/rheostatic view у ЧМЭ3Э.

Первый QA корректно поймал отсутствие кликабельного `GC40P` в одной из связей ЧМЭ3Э. Дефект исправлен добавлением hotspot; требования валидатора не ослаблялись.

Зелёный контроль после исправления:

- ЧМЭ3: **11 effective views, 73 hotspots, 60 directed edges**;
- ЧМЭ3Т: **12 effective views, 77 hotspots, 63 directed edges**;
- ЧМЭ3Э: **15 effective views, 111 hotspots, 92 directed edges**;
- всего по профильным представлениям: **38 views, 261 hotspot, 215 directed edges**;
- profile isolation: **PASS**.

Параллельно `validate_chme3e_stage2.py` остаётся зелёным: 67 применимых общих узлов + 33 профильных узла ЧМЭ3Э, 33/33 подробных карточок, 3 профильные системы, 6 функциональных схем, 29 обозначений и 9 профильных записей источников; утечка ЭДТ ЧМЭ3Т отсутствует.

## Стандарт для следующих локомотивов

Начиная со следующих семейств Stage 2 считается завершённым только при наличии Атласа, обычных электрических/пневматических схем и проверенного интерактивного слоя с profile-safe hotspots/navigation. Отдельно проверенный `SOURCE_OVERLAY` добавляется там, где доступно конкретное исходное изображение схемы.
