# ЧМЭ3Э — этап 1: фундамент и источники

Статус: **COMPLETE**  
Дата: 2026-10-01

## Что зафиксировано

- ЧМЭ3Э выделен в отдельный профиль `chme3e-electronic` внутри семейства `chme3-family`.
- Введён новый канонический путь: `docs/locomotives/diesel/chme3-family/` с разделением `common / chme3 / chme3t / chme3e`.
- Старый `docs/locomotives/chme3/` остаётся только проверенным источником миграции до полного переноса семейства; интеграция должна идти через manifest, а не поиском файлов по имени.
- Подтверждены базовые семейные признаки: дизель семейства K6S310DR, электрическая передача постоянного тока, шесть ТЭД и значительная общность механического/вспомогательного/тормозного оборудования.
- Подтверждены профильные признаки ЧМЭ3Э: дополнительное электронное управление и устройство прогрева дизеля.
- Явно запрещено автоматическое наследование ЭДТ ЧМЭ3Т: у заводского ЧМЭ3Э отсутствуют реостатный тормоз, тормозные резисторы, их охлаждение и CHME3T-EDB runtime actions.
- Для электрической части установлен отдельный профильный слой: ЧМЭ3Э нельзя моделировать просто как базовый ЧМЭ3 или как ЧМЭ3Т с удалённой одной функцией.
- Номерные диапазоны хранятся только как справочная подсказка, а не как достаточное доказательство фактического исполнения после ремонтов/модернизаций.

## Источниковая база этапа 1

Опорный источник — З. Х. Нотик, «Тепловозы ЧМЭ3, ЧМЭ3Т, ЧМЭ3Э», 2-е изд., 1996. Для ЧМЭ3Э отдельно выделены:

- раздел об особенностях электрооборудования ЧМЭ3Т/ЧМЭ3Э;
- глава XVII «Электрическая схема тепловоза ЧМЭ3Э»;
- публичный реестр номерных диапазонов — только как `REFERENCE`, без права определять профильный action gate.

Все источники этапа 1 имеют `NO` / `NO_BY_ITSELF` для разрешения эксплуатационного действия. Точные оперативные действия будут получать authority только после отдельной проверки актуального первичного основания на этапе диагностики.

## Открытые исследовательские вопросы

1. Найти и проверить первичную/заводскую документацию именно по электрическому исполнению ЧМЭ3Э.
2. Проверить действующие эксплуатационные и ремонтные документы, где ЧМЭ3Э явно отделён от ЧМЭ3/ЧМЭ3Т.
3. Учесть изменения комплектации после деповских ремонтов и модернизаций.
4. Отдельно собрать источник для диагностики электронных цепей ЧМЭ3Э.
