# ЧМЭ3 / ЧМЭ3Т — рабочий пакет знаний

Изолированная разработка информационной базы для будущей интеграции в RailBrakeCalculator.

## Текущий статус

Этап: содержательное наполнение после разбора контрактов ВЛ80С/Ермака.

Уже создано:

- `DATA_CONTRACT.md` — единый контракт происхождения, достоверности, конфликтов и допустимости действий;
- `source_registry.json` — стартовый реестр нормативных, учебных, заводских-кандидатов, архивных и полевых источников;
- `profiles.json` — профили ЧМЭ3, ЧМЭ3Т и ЧМЭ3Э с fail-closed правилами для неизвестного исполнения;
- `search_vocabulary.json` — специфичная поисковая семантика ЧМЭ3 и кандидаты для ассистента без дублирования уже существующих общих failure-mode;
- `atlas_index.json` — стартовый стабильный ID-каталог систем и оборудования для последующей привязки карточек, схем, диагностики и приёмки.

## Следующий рабочий блок

1. Развернуть `atlas_index.json` в полноценные карточки оборудования с расположением, назначением, принципом работы, нормальным состоянием, признаками отклонения, схемными и диагностическими связями.
2. Сверить и разметить содержание порядка 996/р для ЧМЭ3 по актуальной редакции; старые 671р-материалы оставить только как исторический/сравнительный слой.
3. Отдельно разобрать аварийные схемы, поиск неисправностей, памятки и полевую практику с маркировкой `FIELD_PRACTICE / CONFLICT / UNVERIFIED`.
4. Собрать маршруты приёмки по главе «Приёмка и сдача тепловоза» и другим проверенным эксплуатационным материалам.
5. После наполнения — автоматическая проверка ID, ссылок, источников, применимости, конфликтов и поисковой семантики.

`Beta` не затрагивается. Работа ведётся только в `feature/locomotive-knowledge-foundation` репозитория `Test-`.
