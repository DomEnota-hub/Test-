# ЧМЭ3 / ЧМЭ3Т — Атлас, заход 2: источник и применимость

## Что подтверждено для наполнения Атласа

1. **Инструкция по эксплуатации двигателя K6S310DR для ЧМЭ3Т, 1988** — скан содержит реквизиты CKD PRAHA и структуру заводской инструкции: устройство, технические данные, обслуживание, уход, демонтаж/монтаж, неполадки. Для описания устройства дизеля, топливной, масляной, водяной систем и наддува это сильный технический источник. Для эксплуатационных действий 2026 года сам по себе не считается достаточным основанием без проверки актуальных документов и конкретного исполнения.

2. **Пособия машинисту по ЧМЭ3 / ЧМЭ3Т / ЧМЭ3Э** — опорный учебный источник для систем, аппаратов и функциональных связей. Используется как `TRAINING_REFERENCE`; обозначения и вариантные отличия проверяются отдельно.

3. **Сборник СЦБИСТ по ЧМЭ3** подтверждает наличие большого массива материалов для дальнейшей сверки: схема электрооборудования ЧМЭ3, схемы ЧМЭ3/ЧМЭ3Т/ЧМЭ3Э, схема тормозного оборудования, пневмосистема, руководство ТО/ТР, поиск неисправностей, основные аварийные схемы приведения в движение, УСТА, электронный регулятор частоты вращения, плакат расположения электрических аппаратов. Сам индекс не повышает статус вложенных документов — каждый материал проверяется отдельно.

4. **Схема электрооборудования ЧМЭ3 из журнала «Локомотив» / ЭТТ** используется пока как техническая публикация для идентификации связей. Номера проводов, контактов, реле и конкретные уставки не переносятся в универсальный слой без проверки варианта.

## Архитектурное решение

Атлас разделён на два уровня:

- `atlas_index.json` — стабильные ID систем и оборудования;
- подробные карточки — назначение, принцип, нормальные признаки, признаки отклонения, связанные узлы, схемы, источники и поисковые термины ассистента;
- `atlas_schemes_functional.json` — функциональные связи систем без ложной точности по проводам/клеммам;
- конкретные принципиальные схемы по исполнениям будут отдельным вариантом поверх функционального слоя.

## Особенность ЧМЭ3Т

Реостатный тормоз выделен отдельным профильным слоем `chme3t-rheostatic`: тормозные резисторы, их охлаждение и аппаратура ЭДТ не считаются общими элементами базового ЧМЭ3/ЧМЭ3Э.

## Обнаруженная техническая задача

При наполнении второго захода выявлены несколько расхождений имен ID между ранним индексом и новыми карточками (`TRACTION-MOTORS`/`TRACTION-MOTOR`, `CONTACTORS`/`MAIN-CONTACTORS`, `BRAKE-RESISTORS`/`BRAKE-RESISTOR`). До закрытия захода они должны быть сведены к одному каноническому набору и проверены валидатором. Это не скрывается и не переносится дальше как технический долг.
