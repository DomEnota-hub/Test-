# RailBrakeCalculator

Android-приложение для расчёта тормозных параметров железнодорожного состава.

Текущая тестовая ветка приложения: **1.2.0-dev1**. В неё добавлены офлайн-справочник и интерактивная схема оборудования ВЛ80С; расчётное ядро и пасхалка разработчика перенесены из проверенной версии 1.1.

Сборка APK выполняется автоматически через GitHub Actions непосредственно из `RailBrakeCalculator.zip` с запуском unit-тестов и Android Lint.
